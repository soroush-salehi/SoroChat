# SoroChat

> A real-time messaging application prototype.

A messaging app foundation with conversation views, message composition, and a planned server-backed real-time transport. The initial milestone is a polished frontend prototype.

## Technology

HTML, CSS, Vanilla JavaScript; PHP API and database planned.

## Roadmap

- [ ] Conversation list
- [ ] Message interface
- [ ] Responsive layout
- [ ] Authentication design
- [ ] Real-time transport

## Project status

Early development. Features are added incrementally and documented as they become available.
